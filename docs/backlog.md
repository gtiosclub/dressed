# Student roadmap and tickets

The first milestone is photo-library selection, manual name/category entry, and saving one clothing item to the closet. Automatic extraction comes later. GitHub records status, assignment and milestones; these links are the local index.

Each ticket uses the agreed short function or UI format. UI tickets include the note that screenshots are preferred in the PR. Read [officer guidance](officers/student-tickets.md) before adding work.
