# Broad APIs can seed Dressed fashion discovery

**Yes, broad product APIs and databases exist, but none verified here supplies a complete, licensed catalogue of PacSun, Hollister, Depop, and Vinted together.** Affiliate networks provide structured feeds from many participating retailers, yet each brand controls access. Marketplace APIs search their own sellers, while commercial discovery vendors search the merchants enabled for a particular account. The most promising evaluation for Dressed is an approved affiliate feed for a durable retail catalogue, alongside a trial of one cross-merchant search API for breadth. Access, mobile display, image use, freshness, and cost need to be checked against actual accounts and agreements before treating any provider as a live source. ([impact.com partner catalogue guide](https://help.impact.com/partner/what-would-you-like-to-learn-about/platform-features/marketing-content/product-marketplace-and-catalogs/download-product-catalogs-as-a-partner); [Firmly Discovery API](https://developers.firmly.ai/api-reference/discovery/))

## Affiliate networks aggregate retailers, with brand-by-brand access

**impact.com, Awin, Rakuten Advertising, and CJ all document multi-advertiser product feeds or product APIs.** impact.com offers partner catalogue downloads through its platform, FTP, or API and normalizes feed fields; Awin offers enhanced-format feeds through a Publisher Product API. Rakuten offers full and delta files, but requires technical approval and approval from each advertiser. CJ documents a searchable publisher Product Feed GraphQL API. These networks reduce the work of parsing many retailer formats, but their coverage is the subset of advertisers that both publish a feed and approve Dressed. ([impact.com](https://help.impact.com/partner/what-would-you-like-to-learn-about/platform-features/marketing-content/product-marketplace-and-catalogs/download-product-catalogs-as-a-partner); [Awin](https://success.awin.com/articles/en_US/Knowledge/Product-Data-Feed-FAQ); [Rakuten](https://pubhelp.rakutenadvertising.com/hc/en-us/articles/11258487715981-Product-Catalog-Data-Feed-Implementation-Guidelines); [CJ](https://developers.cj.com/))

PacSun links to an impact.com affiliate application, making it a concrete brand to approach, but **its feed availability and Dressed's rights to show product images have not been established**. No general Hollister feed was verified in the official material reviewed; its public Style Hub describes a creator programme and storefronts. Affiliate data can include images, price, and links, though feed update timing and permitted image use vary by brand and agreement. Dressed should check whether the particular programme allows an iOS discovery screen, image caching, and later similarity indexing. ([PacSun](https://www.pacsun.com/pacsun/); [impact.com brand catalogue guide](https://help.impact.com/brand/what-would-you-like-to-learn-about/platform-features/product-catalogs/add-product-catalogs-as-a-brand); [Hollister Style Hub](https://community.hollisterco.com/account/faq); [Awin image guidance](https://success.awin.com/s/article/Can-I-use-any-images-from-the-advertiser-s-website?language=en_US))

## Marketplace APIs offer breadth within one marketplace

**eBay Browse and Etsy Open API offer cross-seller search**, giving Dressed broad secondhand or independent-seller results without crawling those sites. eBay Browse supports keyword, category, identifier, and image queries, but production Buy API access requires partner approval; its published default Browse limit is 5,000 calls per day. Etsy exposes active-listing search, with broader commercial use subject to reviewed access. Amazon's Creators API has product search too, but access requires an Associates account with at least ten qualifying sales in the preceding 30 days, and its content caching rules are restrictive for a stored catalogue. ([eBay Browse](https://developer.ebay.com/develop/api/buy/browse_api); [eBay Buy requirements](https://developer.ebay.com/api-docs/buy/buy-requirements.html); [eBay limits](https://developer.ebay.com/develop/api/buy/api_call_limits); [Etsy access](https://developers.etsy.com/); [Amazon Creators API](https://affiliate-program.amazon.com/creatorsapi/docs/en-us/introduction); [Amazon policies](https://affiliate-program.amazon.com/help/operating/policies))

These are **not feeds for the four named brands and platforms**. Depop's documented partner API reads an authorized seller's products, not a public cross-seller discovery catalogue. No official public Vinted catalogue API was verified, and Vinted's US terms prohibit unauthorized scraping and crawling. A Depop seller opt-in partnership or direct Vinted agreement would be separate integrations. ([Depop API reference](https://partnerapi.depop.com/api-docs/reference/); [Vinted terms](https://www.vinted.com/terms-and-conditions))

## Discovery vendors sell search; extraction vendors sell retrieval

**Firmly is a plausible cross-retailer search API to evaluate.** Its Discovery API searches multiple merchants and returns product URLs, prices, and filters, but each App ID sees only authorized merchants. CartAI also documents cross-merchant product search. Public documentation for neither establishes that PacSun, Hollister, Depop, or Vinted would be available to Dressed, or what product/image reuse rights an account would receive. Lykdat searches its existing fashion catalogue from an image, which fits a later visual-similarity experiment rather than bulk catalogue ingestion. ([Firmly Discovery](https://developers.firmly.ai/api-reference/discovery/); [Firmly Search Products](https://developers.firmly.ai/api-reference/discovery/search/); [CartAI Search Products](https://docs.cartai.ai/reference/search_products); [Lykdat API](https://apidocs.lykdat.com/))

**Extraction APIs are a different category.** Diffbot extracts fields from a supplied product URL, and DataWeave and Price API describe collection or price-monitoring services. They can help parse or monitor known pages, but their technical ability to fetch pages does not itself grant Dressed the right to republish a retailer's catalogue or images. They also do not establish comprehensive coverage of the named sources. ([Diffbot Product API](https://www.diffbot.com/docs/extract/product); [DataWeave Data Collection API](https://next.dataweave.com/us/data-collection-api); [Price API overview](https://readme.priceapi.com/docs/an-overview-of-price-api))

## A two-track trial will answer coverage and rights quickly

Run an **affiliate-feed trial** with one approved fashion brand, ideally through the PacSun impact.com route if Dressed qualifies, and a **search-API trial** with Firmly. Ask each provider for the exact merchant list available to Dressed, a sample response for the four named sources, update timestamps, stable IDs, variant handling, outbound links, price and stock refresh, iOS image display and caching rights, similarity-index rights, request limits, and a cost quote at expected traffic. Do not infer coverage from a vendor's network-wide merchant count. ([impact.com catalogue guide](https://help.impact.com/partner/what-would-you-like-to-learn-about/platform-features/marketing-content/product-marketplace-and-catalogs/download-product-catalogs-as-a-partner); [Firmly Discovery](https://developers.firmly.ai/api-reference/discovery/))

For the approved feed, Dressed can adapt a saved sample into its existing SQLite importer and read-only Discovery API. For a search vendor, first test a backend proxy rather than copying every result into a permanent database; the vendor's terms and freshness rules determine what can be stored. The current importer has stable IDs and partial-scan handling, but its source host policy comes from the input feed and must move to trusted backend configuration before live ingestion. ([Dressed catalogue implementation](https://github.com/gtiosclub/dressed/blob/main/backend/catalog/catalog.py); [Dressed catalogue README](https://github.com/gtiosclub/dressed/blob/main/backend/catalog/README.md))

## Conclusion

The choice is less about finding one giant database than **measuring the catalogue Dressed is actually allowed to show**. An affiliate feed is the clearest path to a durable retail index; a cross-merchant search API could add breadth if its approved merchant list and commercial terms hold up. Depop and Vinted remain distinct partnership problems, so neither should be included in a prototype coverage promise without direct evidence.
